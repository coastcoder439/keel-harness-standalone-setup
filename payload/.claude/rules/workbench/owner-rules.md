# Owner-Regeln dieses Workspace

Zweck: Regeln, die nur für diesen Workspace gelten. Claude Code lädt diese Datei in jede Sitzung.

- Jede Regel steht mit Datum und wörtlichem Owner-Zitat: `- [JJJJ-MM-TT] Regel. Owner: „Zitat“`.
- Allgemeine Regeln gehören ins Setup (die Regeldateien des Harness), Projektregeln ins Projekt.
- Der Installer legt die Datei nur an, wenn sie fehlt; ein Upgrade überschreibt sie nie.
