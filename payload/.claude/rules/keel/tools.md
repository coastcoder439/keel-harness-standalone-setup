# Werkzeuge — CLI vor MCP vor Browser

Faehigkeiten in dieser Rangfolge beschaffen: **CLI vor MCP vor Browser** — CLI kostet
null bis zum Aufruf, MCP kostet jedes Kontextfenster dauerhaft, Browser bezahlt Bilder
fuer Buchstaben. Fehlt ein Werkzeug: erst suchen und installieren, dann eine Stufe
absteigen. Streikt eine CLI: Version, Argumente und Schalter pruefen statt absteigen.

**Faehigkeiten, die kein CLI hat** [Owner 26.08.2026, Beleg Spline V2]: Fehlt eine CLI,
ist der offizielle Hersteller-MCP der Weg — und der steht oft in KEINEM Registry, sondern
nur in der Hersteller-Doku oder in einer App gebuendelt. Eine Registry-Suche allein ist
kein Beleg fuer „gibt es nicht".

**Skills feuern nur, wenn zwei Dinge stimmen** [gemessen 26.08.2026 ueber alle
Transkripte dieses Rechners: 74 Skill-Aufrufe, davon 0 spontan aus einem Katalog]:
Muss-Verhalten wird nie der Skill-Description ueberlassen, sondern per Hook, Regel oder
Werkzeug-Kopplung erzwungen; und wenige Skills schlagen viele, weil das Skill-Verzeichnis
nur 1 % des Kontextfensters bekommt und bei Ueberlauf die Descriptions der selten
genutzten Skills verwirft — eine fremde Skill-Flut macht damit die eigenen unsichtbar.
