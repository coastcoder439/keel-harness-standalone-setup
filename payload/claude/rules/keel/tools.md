# Werkzeuge — CLI vor MCP vor Browser

Faehigkeiten in dieser Rangfolge beschaffen: **CLI vor MCP vor Browser** — CLI kostet
null bis zum Aufruf, MCP kostet jedes Kontextfenster dauerhaft, Browser bezahlt Bilder
fuer Buchstaben. Fehlt ein Werkzeug: erst suchen und installieren, dann eine Stufe
absteigen. Streikt eine CLI: Version, Argumente und Schalter pruefen statt absteigen.
